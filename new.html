📚 Belajar 4 Present Tenses

Simple Present | Present Continuous | Present Perfect | Present Perfect Continuous

📖 Simple Present Tense

📐 Pola Kalimat:

(+) S + V1 (s/es) + O (-) S + do/does + not + V1 + O (?) Do/Does + S + V1 + O?

✨ Kapan Digunakan?

  • Kebiasaan sehari-hari → I drink coffee every morning
  • Fakta umum → The sun rises in the east
  • Jadwal → The train leaves at 7 AM

🔄 Present Continuous Tense

📐 Pola Kalimat:

(+) S + am/is/are + V-ing + O (-) S + am/is/are + not + V-ing + O (?) Am/Is/Are + S + V-ing + O?

✨ Kapan Digunakan?

  • Sedang terjadi sekarang → I am reading a book now
  • Kejadian sementara → She is staying at a hotel this week

✨ Present Perfect Tense

📐 Pola Kalimat:

(+) S + have/has + V3 + O (-) S + have/has + not + V3 + O (?) Have/Has + S + V3 + O?

✨ Kapan Digunakan?

  • Pengalaman → I have visited Bali twice
  • Durasi belum selesai → I have worked here for 5 years

⏳ Present Perfect Continuous Tense

📐 Pola Kalimat:

(+) S + have/has + been + V-ing + O (-) S + have/has + not + been + V-ing + O (?) Have/Has + S + been + V-ing + O?

✨ Kapan Digunakan?

  • Durasi dari dulu sampai sekarang → I have been studying for 3 hours
  • Akibat yang terlihat → He is tired because he has been running
